# Источники звуков

Актуально на 25 октября 2026 года. Основной набор сторонних эффектов опубликован под CC0 1.0 / Public Domain. Звук счётной машинки используется по CC BY 4.0 с указанием автора. Отдельно отмеченный пользовательский выбор для сохранения взят с ZvukiPro по условиям самого сайта и требует указания источника. Ссылки сохранены для проверки происхождения перед релизом.

## Сохранение

- **Звуки щелканья пальцами по кнопкам печатной машинки (стандартный)** — пользовательский выбор с ZvukiPro. Имя автора записи на странице не указано; в игре указан сайт как источник.
- Страница: https://zvukipro.com/predmet/190-zvuki-pishuschey-mashinki-pechatnoy.html
- Прямая ссылка, переданная для проекта: https://zvukipro.com/index.php?do=download&id=1470
- Условия: https://zvukipro.com/uslovija-ispolzovanija.html — сайт разрешает обработку и использование в собственных произведениях, просит указать ZvukiPro как источник и запрещает отдельное распространение звуковых файлов для скачивания. Поэтому `audio/licensed/save.wav` не должен попадать в открытый репозиторий как отдельный файл; в сборке звук используется внутри игры. Если планируется платный релиз, коммерческое использование стоит уточнить у сайта.
- **Typewriter Bell.wav**, автор ramsamba — CC0 1.0.
- Источник: https://freesound.org/people/ramsamba/sounds/318687/
- Короткий фрагмент выбранной записи воспроизводится первым; затем без наложения звучит звонок каретки.
- Производный файл: `audio/licensed/save.wav`.

## Собственная музыка

- `audio/variants/music_03_documents.wav` («Документы и часы») создана специально для проекта без сторонних сэмплов и остаётся основной фоновой темой. Помимо низкой середины, в ней с первой секунды звучит спокойный восьмитактовый мотив в диапазоне обычных интерфейсных сигналов. Файл хранится без аудиокомпрессии и нормализован до уровня эффектов, чтобы тема оставалась различимой на наушниках, ноутбуках и обычных мониторах.

Имена авторов и источников звуков приведены на экране «Авторы» в главном меню. При наведении показаны источник, роль записи и условия использования; полный перечень ссылок сохранён здесь.
