# Heir to the Republic v0.9.2

This update gives the downloadable builds consistent English names. The Windows and Linux archives, the executable files, the game window and Windows file properties now use **Heir to the Republic**. English remains the default language; Russian is available in Settings.

Gameplay and save format are unchanged from v0.9.1. Existing saves continue to work.

## How to run

- Windows: extract the archive and run `Heir to the Republic.exe`.
- Linux: extract the archive, allow `HeirToTheRepublic.x86_64` to execute and run it.

Godot is not required.

## Русский

Названия архивов, исполняемых файлов и окна игры теперь на английском. По умолчанию игра открывается на английском; русский язык можно выбрать в настройках. Сохранения v0.9.1 работают без переноса.
