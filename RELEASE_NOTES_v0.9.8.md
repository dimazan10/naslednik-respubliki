# Heir to the Republic v0.9.8

- Rewrote the four main status tooltips in English. Each value range now has its own line, and pending weekly changes are fully translated.
- Replaced character-count line breaks with width-based wrapping. Long tooltips keep their intended paragraphs.
- Added a dark opaque tooltip panel with padding and a border, so text stays legible over the game screen.
- Expanded localization and tooltip checks for pending values, wrapping and the tooltip background.

Saves from v0.9.7 remain compatible.

## Русский

Переписаны английские подсказки казны, поддержки власти, стабильности и поддержки войны. Каждый диапазон значений теперь расположен на отдельной строке, а ожидаемые изменения недели переведены полностью. Длинный текст переносится по ширине панели, у подсказки появился плотный тёмный фон и отступы. Сохранения v0.9.7 совместимы.
